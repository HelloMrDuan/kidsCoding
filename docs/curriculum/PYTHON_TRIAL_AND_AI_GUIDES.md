## 已实现的浏览器试验闭环

- 目录 `P0-U1-L01` 课程详情提供 `/learn/python-lab/P0-U1-L01` 试验入口。
- 编辑 Python 源码 → 点击运行 → Pyodide 0.27.7 执行 Python → 展示标准输出 → 严格检查是否恰好为 `你好，编程世界` → 展示达标或失败反馈。
- SyntaxError、其他运行时异常、加载失败与无限循环超时不会记为通过。
- 这不是服务器远程执行：实验代码仅在浏览器内的 sandbox iframe（不允许同源）与 Web Worker 中运行。脚本执行最长6秒，初始化最多35秒，源代码最多5000字符。
- 这不是可信考试系统：本地页面判定可被浏览器开发者工具篡改；**不写入真实学习进度、不调用成绩提交 API、不会发布其他 Python 课程**。

## 当前运行边界与上线阻塞

- 运行器依赖 `https://cdn.jsdelivr.net/pyodide/v0.27.7/full/`，是 **外部网络依赖**。国内生产环境需要审核 Pyodide 许可并将固定版本的 `pyodide.js`、WASM、stdlib 等资源自托管，使用内容哈希锁定。
- iframe 的 CSP 限制脚本来源和外部连接；依然需要安全评审、浏览器隔离渗透测试、资源与 CPU/内存上限、未成年人输入隐私控制，才可开放通用任意 Python 练习。
- 真实 E2E：`npx playwright test tests/e2e/python-lab.spec.ts --project=desktop`。必须等待浏览器真实加载WASM与执行结果，不允许Mock替代。
- 后续把“第一课严格字符串输出”扩展为多输入、多组隐藏样例的可信评测，应将评测与孩子代码执行隔离，不能把客户端打勾当成正式成绩。
- Scratch 当前只有 `.sb3` 生成和结构校验，**Scratch VM 在线运行尚未实现**；不可以直接引导孩子进入假的 Scratch 关卡。
