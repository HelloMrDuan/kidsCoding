# Golden Lessons · G1 Blockly 故事课堂样板

`G1-U1-L01`《给狐狸一个开场》使用真实 Blockly 和已合入主线的森林剧场故事适配器。Golden 课堂入口为 `/learn/story-lab/G1-U1-L01/golden`，原课堂链接保留。它复用 G0 的品牌和响应式布局基础，集成既有 `LessonWorkspace` 的文件管理、保存、运行、停止及三级任务指引。

课堂用实际运行帧显示狐狸与兔子的位置以及各自对白。小狐狸先说欢迎词再移动才通过基本任务。加演还需要孩子自己接上移动后的提问，可由狐狸提出或切换到兔子演出。纠错关须先观察错误运行。完成前核对各编程关、加演和复盘答案。

新故事课按课 ID 创建教学内容，分别编写启动事件、角色动作、对白、舞台及正反脚本。沿用 `SlotRunAdapter` 传递角色状态及运行判定，避免把动画渲染作为判定。使用 `LessonWorkspace` 的草稿信封，草稿按课程 ID 隔离。每节课独立定义允许积木、提示、失败原因及可重开的代码作品。

在课程目录、成熟度注册表和发布证据账本登记真实入口。校验 Chrome 拖放与运行、错误恢复、四视口及退出重开。路径、角色绘图和舞台台词可以复用已有组件，教学任务和判定应逐课实现。回滚时恢复课程目录到原入口即可继续读取同一草稿格式。正式学习成绩、云端与全站奖励由既有发布门禁管理。

## 本次验证

- 生产构建通过，78 项故事课程、成熟度与发布契约单测通过。
- Chrome 12 项通过，包含 [1440×900](evidence/1440x900.png)、[1366×768](evidence/1366x768.png)、[768×1024](evidence/768x1024.png)、[375×812](evidence/375x812.png) 拖放连接与存储恢复，用实际触控协议覆盖平板和手机。其中 7 项是旧故事课堂回归。

- 角色和森林背景来自仓库既有原创矢量。此课没有新增声音或外部媒体。实体设备与负责人产品验收待完成。
