1440×900 的编辑 SVG 高从旧版 420 px 增至实测 683 px。展开时宽 681 px，收起时宽 931 px，增加约 250 px。对比 [旧界面](before-g0.png)、[桌面设计](g0-design-target.png) 和 [平板与手机设计](responsive-design-target.png)。

五关 E2E 验证计划内失败、三层提示、连错积木拒绝通过、程序导出及导回、异常导入保留程序、写入失败取消离开、手动重试、刷新和作品中心重新打开。停止测试验证中断的运行不会推进课程。[重开后实际回放的作品](reopened-project.png)。

本地共 193 项 Vitest、15 项真实 Chrome 测试通过。Chrome 含 6 项本课测试、4 项同单元回归和 5 项故事、Scratch VM、Pyodide、主线独立启蒙课回归。生产构建和变更范围 TypeScript 通过，ESLint 0 错误并报告 Blockly 共享文件已有的 1 项未用参数警告。全量 TypeScript 仍报告与干净 main 相同位置的 81 条诊断。

平板和手机使用 Chrome 触控输入。实体设备试用、非作者复核和正式产品验收单独记录。
