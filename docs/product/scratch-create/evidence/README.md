[创作中心及实存的多作品列表](1440x900-hub.png)使用 V2 导航、颜色和控件。Scratch 保留原生画布、角色、造型和声音，窄屏先显示舞台和角色。Python 桌面编辑器与控制台并列，窄屏代码在前、控制台在下。触控尺寸检查关键控制在视口内，页面无横向溢出。

[归档测试记录](roundtrip.json)记录导出的实际文件摘要、素材名称、相连积木类型和精灵坐标。一次测试完成新建、添加角色与背景、加入造型与声音、运行、保存、刷新恢复、独立编辑并删除副本、拒绝损坏文件、导入后再运行，以及重新打开原作。另一次测试让 IndexedDB 写事务失败，确认错误可见、编辑器保留，并验证重试保存和刷新恢复。

[Python 归档与运行记录](python-roundtrip.json)包含导出源文件的 SHA-256、完整源码和重新导入后实测输出。浏览器还验证了编辑器搜索、撤销重做、字体大小、控制台输入、标准错误、异常行、手动停止、执行超时、引擎初始化失败、内存压力和恢复。两个编辑器均检查未保存内容的离开确认与本机写入失败后的重试。Scratch 双窗口用例核对旧版本拒写、导出，以及重新加载新版。

触控验收由 Playwright 在 Chrome 中执行。实际设备体验、预发布两个真实账号的完整流程、公开发布前的许可复核仍待验收。
