# OPS-050 浏览器验收

截图来自本地生产构建、Windows Chrome 157.0.8103.52 和独立来源托管的 Scratch Foundation GUI 15.3.0。桌面使用鼠标。平板和手机用 Chrome 触控事件拖入并连接真实积木，再点击绿旗和保存。测试读取 Scratch 原生导出的 `.sb3`，确认两个积木实际连接，以及项目刷新后恢复。

[创作中心及实存的多作品列表](1440x900-hub.png)使用 V2 导航、颜色和控件。全屏编辑器保留 Scratch 原生画布、角色、造型和声音布局。窄屏先显示舞台和角色，再显示积木与脚本。两种触控尺寸检查角色卡未被舞台下方面板裁切、编辑器无横向溢出、保存按钮完全可见。

[归档测试记录](roundtrip.json)记录导出的实际文件摘要、素材名称、相连积木类型和精灵坐标。一次测试完成新建、添加角色与背景、加入造型与声音、运行、保存、刷新恢复、独立编辑并删除副本、拒绝损坏文件、导入后再运行，以及重新打开原作。另一次测试让 IndexedDB 写事务失败，确认错误可见、编辑器保留，并验证重试保存和刷新恢复。

触控验收由 Playwright 在 Chrome 中执行。线下真机体验、预发布双源配置及公开发布前的许可复核仍待验收。
