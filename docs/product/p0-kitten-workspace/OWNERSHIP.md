## 二、边界规则

- 课程特定模块分别归 3、4 号，互不写对方文件；共享文件改动须经首席。
- 任何账号不得单方面改视觉 token、布局尺寸与按钮体系；工作区新增 token 由首席冻结。
- 工作流文件与目录 / 台账文件归首席受控串行；一次只合一个改动台账的 PR，后合者以新主线为基重建。
- 共享核心只有一个权威实现，样板不得自带复制核心，发现即退回。
- 课节 PR 建 PR 时把本课台账条目置为 in_review 并填真实 PR 证据；合并后课节继续 in_review，不转 completed（独立教研、儿童试学、发布审核未做前不升 completed）。
- 本规范 PR 自身任务为 SPEC-001（产品台账新行，in_progress），仅为门禁登记；课程台账（432 节）未动，共享 UI 与教学逻辑未动。

## 三、评审路由

- 四号课程（P3 / C0 / C1 / A1）由首席第一复核，三号在首席指定时交叉复核。
- 2 号 / 三号课程由四号复核（非作者）+ 首席验收。
- AI 技术复核不代独立人工教研；真实儿童试学须监护人同意；最终发布由 duan 批。
