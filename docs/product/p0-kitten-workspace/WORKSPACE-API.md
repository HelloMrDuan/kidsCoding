# LessonWorkspace 组件与引擎适配器接口

版本：`p0-kitten-workspace-v1.0`
地位：本文件定义共享工作区与引擎之间的契约。改接口须经首席裁定并附回归证据。

## 一、LessonWorkspace 外壳

### 输入

- `lessonContract`：见 `LESSON-CONTRACT.md` 全部字段。外壳不得硬编码课程标题、任务文案或答案。
- `engineAdapter`：见第二节，任一适配器均须实现同一接口。

### 插槽

舞台区、角色管理列、积木分类与素材面板、脚本工作区、反馈区、任务抽屉。A1 类非积木课：右侧插槽换为摘要编辑、事实核对与结果预览，不强行塞进积木布局。

### 事件

- `onSave(draft)`：草稿已写入（分键，见第四节）；写入失败不触发，UI 显示“未能保存”。
- `onRun(result)`：一次运行完成，`result` 含第三节三层判定对象。
- `onStop()`：运行被中断；脚本与已得状态保留。
- `onFeedback(text)`：反馈区文本更新；文本须与真实运行结果一致，不得用预设分数。

### 状态规则

单一工作区状态对象；切换工作区、折叠抽屉、缩放舞台、切换标签均不得重建引擎、不得丢失脚本或草稿。

## 二、引擎适配器接口（不新造 VM）

共享工作区必须承载仓库已有 Scratch VM / Blockly 资产，复用现有持久化和导入导出能力。禁止重新发明一套与 Scratch 语义不兼容的积木系统；禁止用静态积木图片或按钮模拟代替正式编辑器。

| 方法 | 约定 |
|---|---|
| `mount(el)` / `unmount()` | 挂载与卸载；卸载后不得残留监听与定时器 |
| `loadScript(script)` / `getScript()` | 脚本读写，格式沿用现有工作区与草稿 / .sb3 机制 |
| `run(onEvent)` / `stop()` | 运行走真实引擎，观察通道（按键、运行帧、精灵 / 角色状态）出反馈；停止必须可中断并保留脚本与已得状态 |
| `getState()` | 返回舞台与角色真实状态，供判定使用 |

三类适配器：

- `ScratchVMAdapter`：复用 `features/scratch-vm` 与 `scratch-g2-lab` 的 VM 接线与观察通道。
- `BlocklyAdapter`：复用现有 Blockly 工作区。
- `SummaryAdapter`：A1 摘要编辑与事实核对，非积木。

必须验证：真实积木连接、循环嵌套、参数修改、角色状态、舞台执行、停止行为。

## 三、运行生命周期

1. **复位**：每次运行舞台复位（角色回起点、分数清零），多次运行同一脚本结果一致。
2. **执行**：按脚本内容真实执行（移动、循环展开、角色状态变化），执行步骤可追溯。
3. **观察**：运行中与运行后均可从 `getState()` 读到真实舞台状态。
4. **判定**：一次运行同时输出三层（舞台结果 / 任务判定 / 知识证据），UI 三行分别呈现；“已掌握”“已完成”只在任务与知识证据同时通过时出现。
5. **反馈**：反馈文案与三层判定一一对应；失败须写明哪一层未通过与差值，不只写“不对”。
6. **停止**：运行中停止须取消待完成的判定与动画，保留脚本；停止后重跑结果与首次运行一致，分数不叠加。

## 四、草稿隔离

- 草稿按课节分键保存，键含 `lessonId`（格式 `kidscoding-draft:{lessonId}`）。
- 切换课节时先保存当前课、再载入目标课；选句、事实核对、提示、草稿、反馈全部绑定本课节，不得跨课残留。
- 保存失败必须显示“未能保存”，不得显示“已保存”（fail-closed）；文件菜单操作（新建 / 保存 / 导出 / 导入 / 恢复初始）关闭菜单后生效状态须可见。
- 草稿内容只含本课数据（脚本或选句）；运行状态（位置、分数）不跨课保留。

## 五、响应式状态规则

- 桌面 1440：四区同屏；平板 768：舞台行可隐藏，角色行与积木 / 脚本两栏；手机 375：四工作区切换 + 脚本区内素材抽屉。
- 布局切换只改可见性与列宽，不重建引擎、不重置脚本、不丢草稿。
- 运行按钮在脚本工作区内可达（手机端不依赖切回舞台标签）；摘要检查按钮在摘要编辑区内可达。
