# 三项验收及反向测试

版本：`p0-kitten-workspace-v1.0`
地位：两节样板提交用户确认前必须分别通过 A、B、C 三项；任一失败样板不得完成，不得提交用户确认。

## 一、A：UX 验收

- 布局紧凑、真正可编辑；桌面 1440、平板 768、手机 375 三端操作有效，手机不再只是可以显示。
- 手机端完整操作链真实可用：素材抽屉点积木插入、↑ ↓ 排序、✕ 删除、改参、脚本区内直接运行。
- 切换工作区、折叠抽屉、缩放舞台、切换标签均不丢脚本、不重建引擎。
- 保存状态真实可见；保存失败显示“未能保存”，不得显示“已保存”。

## 二、B：内容一致性验收

- 标题、目标、当前任务、运行引擎、判定、反馈、总结一一对应，不跨课污染。
- 课节切换六方全换（标题、目标、任务、提示、结果、总结），不得只换标题。
- 草稿按课节分键，切换往返后脚本与选句完整。
- 14 条内容强制规则与自动化一致性门禁通过，含故意错误绑定反向测试。

## 三、C：教学质量验收

- 学生知道本节主题，先思考再编程，有独立解决过程和迁移任务，不能照抄完整积木脚本过关。
- 首屏五要素齐全；三层活动（探索理解 / 独立解决 / 迁移创作）齐全；难度递进有分步表；提示三级逐步揭示，完整参考实现只在事后节点出现。
- 课后理解证据五项（独立完成关键操作、理解核心积木作用、预测变化后结果、解释一个错误、在相似不同任务中应用）不得虚构为掌握。
- 任务类型诚实标注：教学定向关卡可限定知识点；开放创作按行为目标多解法；评测缺口必明说，不得冒充。

## 四、反向测试清单（原型级，正式样板须在真实引擎上重做）

判定三层分离；水果 x=200、阈值 80（原型演示值，正式参数以首席裁定为准）：

| 编号 | 输入 | 预期 |
|---|---|---|
| R1 | 只有绿旗 | 舞台没接住、任务未完成、知识证据未通过、结论未合格 |
| R2 | 无循环但接住（右移 100 + 右移 30） | 任务完成、知识证据未通过，不得写“已掌握循环” |
| R3 | 参数错误（右移 10） | 未接住、结论未合格 |
| R4 | 移动正确但未达目标（右移 30 + 右移 30，x=60） | 未接住 |
| R5 | 结构不同但行为达标（右移 100 + 右移 50，x=150） | 任务完成（按行为判定，不逐块比对） |
| R6 | 循环版（重复 3 次右移 50，x=150） | 结论合格（任务与知识证据都通过） |
| R7 | 运行中停止后重跑、再次运行 | 停止时分数仍 0、脚本保留；重跑结论合格分数 1；再次运行分数仍 1 不叠加 |
| M1 | 手机端抽屉插入、改参、↑ 排序、✕ 删除、脚本区内运行、切标签 | 每步真实生效；运行任务完成；切标签后脚本保留 |
| A1 | G2 脚本保存 → 切 A1 → 选 A/B/C 保存 → 切回 G2 → 再切 A1 | 抽屉与简报只显示本课内容；往返后 G2 脚本与 A1 选句完整；A1 检查合格且无水果反馈残留 |

## 五、证据要求与禁止

- 证据：三端真实浏览器测试（1440 / 768 / 375）+ 截图或录屏 + 测试结果；原型测试不能代替课程 E2E。
- 复核：非作者技术复核、独立视觉审核、适当实际用户试用；正式儿童试学须监护人同意与隐私要求；开发者复核不能代替用户体验确认。
- 禁止：批量迁移 432 节；开发新的无关课程；用静态积木代替正式编辑器；仅因原型测试通过就宣称正式课堂完成；在没有真实教学证据时显示“已掌握”“已完成”。
