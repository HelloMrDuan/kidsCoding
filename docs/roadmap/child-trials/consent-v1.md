# kidsCoding 儿童试学 · 监护人知情同意书（v1）

尊敬的家长/监护人：

我们正在开发面向 5～13 岁儿童的图形化编程课程 kidsCoding。课程尚在**实验阶段，未正式发布**。我们邀请您的孩子参加一次课程试学，帮助我们发现课程中难懂或不好用的地方。

## 试学内容
- 在您家或约定地点，用平板/电脑浏览器体验 1～2 节课（单次不超过 30 分钟）。
- 全程有成年观察人陪同；孩子可以随时停下，无需说明理由，不会有任何影响。

## 我们记录什么
- 只记录：匿名编号（如 C01）、年龄、是否完成、用时、提示次数、卡住的地方、孩子对课程的简短评价（转述）。
- **不记录**：姓名、学校、班级、联系方式、照片、录音、录像。
- 课程作品仅保存在本设备浏览器中，不上传；朗读功能使用浏览器自带语音，不录音。

## 数据用途与保管
- 记录仅用于改进课程，以匿名形式保存在项目记录中。
- 本同意书签署件由项目负责人线下保管，不公开、不上传。
- 您可以随时要求删除孩子的试学记录。

## 可选项（不勾选即为不同意）
- [ ] 同意录制**屏幕操作**（不录人脸和声音），仅供内部复盘，复盘后删除。
