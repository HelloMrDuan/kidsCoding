## 0. 产品交付的两条并行泳道与优先级

- **产品前台泳道 UX**：设计系统 → 地图 → 图形课堂 → 作品夹 → Scratch/Python → 目录/家长/后台 → 官网完成度。
- **课程引擎泳道 EDU**：双角色毕业 → 统一课程 ID/进度/发布 → G0 一单元 → Scratch/Python 逐单元 → 432 课程逐一转化。
- **教学品质泳道 TQ**：严格按 [09 课程教学品质](./09-TEACHING-QUALITY-GATE.md) 执行 TQ-001～007，每节要有情境/预测/不同动手/真实错误/自主作品/反思，按 [10 课例](./10-TEACHING-QUALITY-EXEMPLARS.md) 实测。和页面视觉独立评分。
- **交汇规则**：UX 不能制造尚未实现的引擎动作；EDU 的功能 PR 不能忽视基础适龄 UI；重要课程合并前至少含地图/课堂可用路径。
- **当前真实起点**：main `57eb686d820700142c10602e87173459a0e5632a`；第一至九节独立 Blockly 已可运行但无 UI 成熟度验收；第 10～12 节尚未进 main，某候选代码分支未验收；432 目录全未标正式可玩。
- **如何优先**：先消除儿童关卡错误/不可运行 P0，然后以 1 个页面 PR + 1 个课程 PR 小步交付；不能做完 432 节再开始改界面，也不能只做官网营销。

## 9. 评审打分：明确什么叫“接近国内顶尖”

五项合计 100 分，每次 PR 附证据；既评价视觉，也评价实用性：

| 维度 | 分值 | 判定方法 |
| --- | ---: | --- |
| 视觉成熟度 | 30 | 整体版式与信息层次 10、原创美术/角色场景 10、组件细节 10，截图同行评审 |
| 真实功能 | 30 | 运行/编辑/错误/保存/导航各实际通过，不能靠视觉假动作 |
| 教学有效性 | 20 | 知识目标、手动练习、错误复盘、自由改造/作品证据 |
| 跨端体验 | 10 | 1440、768、375 和至少一个触控场景，没有遮挡/横向滚动 |
| 可用与可信 | 10 | WCAG AA 基线、原创素材/许可、隐私与真实数据口径 |

- **≥90 分**：可标记“成熟体验候选”，仍须真实生产验收才可宣称正式达到。
- **80–89 分**：继续优化，暂不对外声称成熟对齐。
- **＜80 分**：退回 PR 或仅保留内部试验。
- **硬否决**：假 Scratch/Python 执行、按钮无效、抄用未授权 IP、个人信息泄露、未经批准宣称正式发布、缺关键三断点回归，**无论多少分都不能合并为可发布功能**。
