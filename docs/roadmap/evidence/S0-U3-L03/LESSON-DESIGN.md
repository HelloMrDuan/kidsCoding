# S0-U3-L03《尊重创作者授权》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-s0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《尊重创作者授权》、知识点“信息素养”、
  预期“能使用信息素养解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 作品与许可类型均为虚构实现选择，不得说成详细稿规定值；本课不使用
  任何真实作品。
- 详细稿缺失需主架构补齐后复核。

## 目标
- 尊重创作者授权：按许可类型做事——可自由使用直接用；署名可用须署名
  再用；须先获许可先问再用，绝不直接用；不可用一律不用。至少处理 4 件
  作品，含至少 1 件先获许可与至少 1 件不用，同一作品不得重复处理。
- 练习 A：故事A 可自由使用直接用；歌曲B 署名可用署名再用；图片C
  须先获许可先问；故事D 不可用不用。
- 练习 B：歌曲E 可自由使用直接用；图片F 署名可用署名再用；故事G
  须先获许可先问；歌曲H 不可用不用。
- 找错：须先获许可直接用；不可用却用；署名可用未署名就用；作品重复；
  只有 3 件作品。
- 拓展：再加第 5 件作品。
- 分层提示：1）许可写的是什么？2）可以直接用吗？3）要先问谁？
