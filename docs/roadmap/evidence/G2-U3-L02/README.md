## 五、测试发现并已修复的缺陷（保留记录）

1. **循环归属误判（沙箱）**：Scratch 里排在循环后面的积木，其 `parent` 指向循环块。最初的祖先遍历把 `循环 ... 右移 100` 里循环后面的 `右移 100` 误判为“在循环里”，导致“偶然接住”程序的知识证据被错判通过。由“偶然接住”真实 VM 用例发现，改为区分循环体（SUBSTACK）与后续积木（next）。
2. **选中状态丢失（编辑器）**：Blockly 12 把选中绑定到键盘焦点，点击工具栏按钮后 `getSelected()` 变 null，手机端 上移 / 下移 / 删除 / 数字框全部失效。改为编辑器按 ID 自己记录选中。
3. **符号字形缺失（界面）**：`①②③④ ▶ ■ ✕ ✓` 在没有这些字形的设备上显示为方框。全部改为纯文字。
4. **“已恢复”提示被自动保存覆盖（界面）**：恢复草稿后立刻被“已保存”覆盖。改为内容没变不重复保存。
5. **平板舞台过大、手机底部被全局导航遮挡（布局）**：舞台限宽 380px；手机根容器底部留出全局导航高度。
6. **教学参数文档错误**：探索关最初用 2×30，真实 VM 证明它恰好接住（相差 40 = 容差）。已改为 2×20 并在 `TEACHING-PLAN.md` 记录。
