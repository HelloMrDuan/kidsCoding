## 实际功能与教学闭环

真实 Blockly 连接顺序进入教学解释器。狐狸与小熊各有位置、对白和动作状态；狐狸走 100 步、小熊走 200 步，且整段程序成功结束后，才标记礼物找到。起点观察、只完成一个目标、少走/多走或到位后追加错误动作都没有成功礼物。不是完整 Scratch 多脚本 VM。

观察两个 0 步起点与 100/200 步目标 → 预测切换后谁重复移动（猜错也可以实验）→ 狐狸独立移动、熊留在起点 → 切换后熊移动并再做一次 → 故意让熊少走一次，看到实际 100/100 且没有礼物 → 补一次移动修复 → 选择自己的方案、解释动作归属 → 本机保存、重开运行、编辑和重新验证保存。

标准方案：开始、狐狸移动、切换、小熊移动、再做一次。另一个有效方案：小熊接两块移动。作品步骤可另加狐狸问候、小熊庆祝；判定实际距离，不限定唯一答案。“再做一次”接在当前角色刚做的移动之后，只再执行一次该移动；不能跨切换借用狐狸的动作，也不是包含积木的循环容器。

重跑从零开始；重置、改动程序会撤销礼物及通过状态，并取消尚未执行的动作。完成页使用可运行作品，支持真实修改、重验和本机保存。直接打开完成 URL，缺完成记录或作品时显示回课堂入口，不伪造毕业。浏览器写入失败保留原进度、不发奖励、不跳完成页，可重试；作品保存不冒充云发布。第二次实际完成全部五步仍只有一份课程/作品记录、一次星星及去重徽章/卡片。
