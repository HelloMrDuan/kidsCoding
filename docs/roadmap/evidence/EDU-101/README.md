# EDU-101：第 10 课真实双角色交付证据

2026-10-11；课程 `lesson-10-second-friend`。基线 `691d99844e5d382118d64661150ec206d0277b29`。本任务只实施第 10 课，第 11/12 课继续 todo。工程验收不等于生产发布、儿童实测或教研认证。

## 实际运行与教学

- 真 Blockly 工作区的连接程序由受限顺序解释器逐块执行；每次移动增加当前角色 100 步，两个角色的坐标和动作状态分开。不是完整 Scratch 多脚本 VM。
- 开始时恢复两个起点。运行中可重置，取消剩余指令；编辑程序撤销旧通过状态。脱离开始的积木拒绝执行。
- 观察两个 0 步起点 → 预测切换后谁移动（猜错仍可实验）→ 狐狸 100/熊 0 → 狐狸 100/熊 100 → 亲手漏切换并观察狐狸 200/熊 0，再修复 → 制作可选狐狸问候的作品并解释动作归属。
- 错误练习必须亲自运行漏切换程序；正确程序不能跳过该活动。提示由孩子逐层打开：现象、独立角色概念、正确操作。
- 两个有效作品：`开始→移动→切换→移动`；`开始→移动→狐狸问候→切换→移动`。成功由实际位置判断，不只比对固定答案。
- 课内草稿使用既有 sessionStorage；完成作品使用既有 localStorage 项目快照。完成页能重新运行、修改、重新验证及保存；代码变化后保存按钮失效。保存失败显示真实失败。这里是本机练习，没有增加云同步或认证分数。
