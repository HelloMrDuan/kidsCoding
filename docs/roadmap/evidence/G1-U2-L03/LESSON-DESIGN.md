# G1-U2-L03《让角色沿路走》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U2-L03，年龄 6-9 岁，引擎 blockly。
故事：森林邮差需要先向东后向北送信。

## 目标
- 分解为向右80、向上40、向右20三段移动。
- 验证：角色最终位移(+100,+40)。

## 找错
- 漏走第二段导致目标点错误：在每次位移后记录当前位置。
- 顺序错误、距离错误、缺少开始事件均为失败。

## 拓展
- 设一个障碍要求走折线：执行器中以 obstacle_detour 标出绕障，
  不改变三段位移与最终位移时通过。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 前置课 G1-U2-L02 尚在 PR #282 待审核未合并，本课台账登记不写
  对未合并任务的依赖，前置关系仅在本设计与 PR 描述中说明。
