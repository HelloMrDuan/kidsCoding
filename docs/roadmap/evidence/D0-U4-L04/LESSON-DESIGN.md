# D0-U4-L04《无障碍内容检查》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-d0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《无障碍内容检查》、知识点“数据”、
  预期“能使用数据解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 检查项与标准均为实现选择，不得说成详细稿规定值。
  详细稿缺失需主架构补齐后复核。

## 目标
- 无障碍内容检查：至少 3 个内容项；图片要有替代文本，视频要有字幕，
  文本字号至少 14；每项本身必须合格，另需至少一条修复记录。
- 练习 A：图片有替代文本、视频有字幕、文本 16 号，第 4 张图片补替代文本；
  练习 B：图片有替代文本、文本 14 号、视频有字幕，第 4 项文本 16 号并有修复记录。
- 找错：图片无替代文本；视频无字幕；少于 3 项；无修复记录。
- 拓展：再加第 5 张图片并有替代文本。
- 分层提示：1）这是什么内容？2）它需要什么？3）修了吗？

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 不是基于详细稿的课程，详细稿缺失须另行补齐。
- 前置课 D0-U4-L03 尚在 PR #369 待审核未合并，本课台账登记不写
  对未合并任务的依赖，前置关系仅在本设计与 PR 描述中说明。
