# D0-U3-L05《观察用户反馈》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-d0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《观察用户反馈》、知识点“测试”、
  预期“能使用测试解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 反馈内容均为实现选择，不得说成详细稿规定值。
  详细稿缺失需主架构补齐后复核。

## 目标
- 观察用户反馈：每条反馈有步骤、预期、实际三栏，至少 3 条，至少一个修复引用已记录的反馈。
- 练习 A：导览反馈 3 条（顺序错、缺少讲解、指示不清），修复 f1；
  练习 B：信号反馈 3 条（绿灯太短、黄灯不清、无红灯倒计时），修复 s2。
- 找错：只问喜不喜欢无复现步骤；修复引用未知反馈；少于 3 条。
- 拓展：第二轮复测 f1，结果为已修复。
- 分层提示：1）用户怎么做的？2）应该怎样？3）实际怎样？

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 不是基于详细稿的课程，详细稿缺失须另行补齐。
