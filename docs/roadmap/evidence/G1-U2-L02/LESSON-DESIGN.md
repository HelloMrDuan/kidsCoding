# G1-U2-L02《移动到目标点》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U2-L02，年龄 6-9 岁，引擎 blockly。
故事：兔子收到一张藏宝地图，坐标标的是(-80,20)。

## 目标
- 通过设置坐标让兔子直接到达藏宝点。
- 验证：精灵最终x=-80,y=20。

## 找错
- 坐标超出舞台或符号写反：对照地图的零点和负数方向。
- 舞台范围实现选择：x 在[-240,240]、y 在[-180,180]（Scratch 舞台范围），
  详细稿只说“超出舞台”，未规定数值，不得说成详细稿规定值。

## 拓展
- 另加一个目标点让玩家二选一：执行器中以标点方式加第二目标点，
  最终位置仍为藏宝点时通过。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 前置课 G1-U2-L01 尚在 PR #281 待审核未合并，本课台账登记不写
  对未合并任务的依赖，前置关系仅在本设计与 PR 描述中说明。
