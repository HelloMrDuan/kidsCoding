## 教学目标

学生能按“供电 → 接光敏传感器 → 读至少 3 个数 → 按读数报告级别”的顺序完成一次模拟输入读取，并说清报告必须从读数算出来，不能猜。

## 情景与知识

- 情景：光敏传感器接在 A0，供 5V 电，读到 100、500、900，报告为暗、中、亮。
- 知识：合格读取 = 供电必须是开始后第一个积木且电压恰好 5V + 传感器引脚只能是 A0、A1 + 至少 3 个读数且每个都是 0–1023 的整数 + 恰好一个报告积木且在最后一个读数之后 + 报告级别与读数算出的级别按顺序完全一致。
- 级别分界（实现选择，必须讲明）：小于 300 为暗，300–700 为中，大于 700 为亮；300 与 700 都算中。
- 安全与真实性说明（课堂必须讲明）：本课只是模拟模型，不读真实传感器，不得冒充真实测量；真实传感器工作必须在断电时由老师或监护人指导接线，只用开发板规定的电压。

## 亲手练习（目标不同）

- 练习 A（主课）：读数 100、500、900，报告暗、中、亮。
- 练习 B（测分界）：读数 250、300、701，报告暗、中、亮，300 与 701 用来检验分界。

## 找错

- 读数 1200 超出 0–1023、读数只有 2 个：均失败。
- 报告级别与读数算出的不一致：失败，说明报告是猜的。
- 传感器引脚 A5、电压不对：均失败。
- 缺少传感器、缺少供电、缺少报告、缺少开始事件：均失败。

## 分层提示

- 第一层：先看供电和传感器接对没有。
- 第二层：再数读数够不够 3 个，是不是都在 0–1023 内。
- 第三层：按分界一个一个算级别，再对照报告，不要先写报告再算。
