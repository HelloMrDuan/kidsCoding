# D0-U3-L02《设计防洪警报》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-d0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《设计防洪警报》、知识点“需求”、
  预期“能使用需求解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 水位与阈值均为实现选择，不得说成详细稿规定值。
  详细稿缺失需主架构补齐后复核。

## 目标
- 设计防洪警报：水位＜50 安全，50–79 预警，80＋ 危险；每个读数状态必须正确，且至少触发一次警报。
- 练习 A：30 安全、60 预警、90 危险；练习 B：45 安全、55 预警、75 预警。
- 找错：90 报成预警；警报从未触发；少于 3 个读数。
- 拓展：再加读数 100 危险。
- 分层提示：1）水位是多少？2）到哪个阈值了？3）警报该是什么？

- 不是独立教研，不是儿童试学，不得标 completed。
- 不是基于详细稿的课程，详细稿缺失须另行补齐。
