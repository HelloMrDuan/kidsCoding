# S0-U3-L04《友善的网络表达》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-s0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《友善的网络表达》、知识点“信息素养”、
  预期“能使用信息素养解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 留言示例均为虚构教学示例，不得说成详细稿规定值；示例中的不友善
  说法只用于识别与改写，绝不对真实的人说。
- 详细稿缺失需主架构补齐后复核。

## 目标
- 友善的网络表达：至少写 4 条留言，含至少 1 条友善、1 条中性、1 条
  不友善留言；每条不友善留言必须恰好改写一次，改写内容非空且不含
  不友善词语；非不友善留言不需要改写。改写原则：说具体做法、给建议，
  不攻击人。
- 练习 A：友善“你的画颜色真好看”；中性“我看到你画了一只猫”；
  不友善“你画得真难看”改写为“可以再试试不同的颜色”；友善
  “谢谢你的分享”。
- 练习 B：中性“这是一个故事”；不友善“你写得真差”改写为
  “可以再改改结尾”；友善“我喜欢这个开头”；中性“我读完了”。
- 找错：不友善留言无改写；改写仍含不友善词语；给友善留言加改写；
  留言编号重复；只有 3 条留言。
- 拓展：再加第 5 条友善留言。
- 分层提示：1）这句话听着舒服吗？2）它在说人还是说事？
  3）换成建议怎么说？

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 不是基于详细稿的课程，详细稿缺失须另行补齐。
