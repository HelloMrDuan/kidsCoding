## 教学目标

学生能用状态解释电机速度调节：速度从 0 开始，加速加 1 档、减速减 1 档、停止回到 0，最高 3 档、最低 0 档，到顶和到底都不再变化，并说清每一步的速度是怎么算出来的。

## 情景与知识

- 情景：电机接引脚 5，供 5V 电，命令是加速、加速、减速、停止，速度是 1、2、1、0。
- 知识：合格调节 = 供电必须是开始后第一个积木且电压恰好 5V + 电机引脚 5 + 至少 3 个命令且每个只能是加速、减速、停止 + 恰好一个速度积木且在最后一个命令之后 + 速度序列必须与命令算出的一致。
- 状态规则（实现选择，必须讲明）：速度一开始 0（停）；加速加 1，最高 3，到顶仍是 3；减速减 1，最低 0，到底仍是 0；停止直接回到 0。档位含义：0 停、1 慢、2 中、3 快。到顶到底不算错，这是限幅，不是故障。
- 安全与真实性说明（课堂必须讲明）：本课只是模拟模型，不驱动真实电机，不得冒充真实运行；真实电机工作必须在断电时由老师或监护人指导接线，只用开发板规定的电压，手指、头发、宽松衣服远离转动部分。

## 亲手练习（目标不同）

- 练习 A（主课）：命令加速、加速、减速、停止，速度 1、2、1、0。
- 练习 B（到顶限幅）：命令加速、加速、加速、加速、减速，速度 1、2、3、3、2；第四次加速到顶，速度仍是 3，不是 4。

## 找错

- 命令“极速”不在加速、减速、停止中、命令只有 2 个：均失败。
- 速度序列与命令算出的不一致：失败。
- 电机引脚 6、电压不对：均失败。
- 缺少电机、缺少供电、缺少速度、缺少开始事件：均失败。

## 分层提示

- 第一层：先看供电和电机接对没有。
- 第二层：再数命令够不够 3 个，是不是只有加速、减速、停止。
- 第三层：从 0 开始一步一步算：加速加 1、减速减 1、停止回 0，到顶到底不动。

## 创意拓展
