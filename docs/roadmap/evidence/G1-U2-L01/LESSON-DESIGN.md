# G1-U2-L01《认识舞台坐标》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U2-L01，年龄 6-9 岁，引擎 blockly。
故事：小狐狸找不到舞台中心，导演在地上画出坐标网格。

## 目标
- 将狐狸放到(x=0,y=0)，再分别移动到(60,0)和(60,40)。
- 验证：角色最终定位在(60,40)。

## 找错
- 把x和y调换而停在(40,60)：先看横轴，再看纵轴，逐个读出坐标值。
- 跳过中间点、终点错误、缺少开始事件均为失败。

## 拓展
- 标出左上、右下的坐标点。执行器示例用(-120,120)与(120,-120)，
  是实现示例，不是详细稿规定值。
