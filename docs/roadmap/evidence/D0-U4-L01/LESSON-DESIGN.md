# D0-U4-L01《写一段科普剧情》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-d0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《写一段科普剧情》、知识点“叙事”、
  预期“能使用叙事解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 场景与科普点均为实现选择，不得说成详细稿规定值。
  详细稿缺失需主架构补齐后复核。

## 目标
- 写一段科普剧情：至少 3 个场景，每场景有旁白和科普点，
  非结论场景科普点不重复，必须以结论场景结尾且结论复述前面一个科普点。
- 练习 A：提问→实验→结论（水加热变水蒸气）；
  练习 B：提问→观察→结论（叶子有叶绿素）。
- 找错：场景缺少科普点；非结论场景科普点重复；无结论场景。
- 拓展：在结论前加应用场景。
- 分层提示：1）剧情分几幕？2）每幕讲了什么科普点？3）结论复述了吗？

## 明确不是什么

- 不是独立教研，不是儿童试学，不得标 completed。
- 不是基于详细稿的课程，详细稿缺失须另行补齐。

## 诚实记录的修正
- 首版执行器要求全部科普点不重复，与“结论复述前面科普点”自相矛盾，
  首次运行即失败；已修正为仅非结论场景科普点不重复，结论可复述。
- 首版两个测试索引数错（删/改了旁白而非科普点），已修正测试索引，
  执行器未因此改动。最终 8 个测试全部通过。
