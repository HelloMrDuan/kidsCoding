# G1-U3-L01《点击打开宝箱》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U3-L01，年龄 6-9 岁，引擎 blockly。
故事：宝箱封着一张奖励卡，要点箱子才能打开。

## 目标
- 绑定宝箱点击事件，使封闭造型变成打开造型。
- 验证：未点击时保持关闭，点击一次才开启。

## 找错
- 点击空白背景也打开宝箱：核对事件究竟绑定哪个精灵。
- 事件绑定舞台、缺少点击绑定均为失败。

## 拓展
- 加一次性防重复开启状态：第二次点击已打开的宝箱仍保持打开，
  不会又变回关闭。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
