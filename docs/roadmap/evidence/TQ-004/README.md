## 结论：验收不通过（不能标 completed）
六节课都是 **L1 详案**（`contentStage: detailed_script`、`playable: false`、`codeReady: false`）。产品里没有任何一节可以亲手拼块运行，所以 TQ-004 的验收项“两种有效练习、反例/分层提示、单元可演示作品”无法满足。

六节共同缺陷：
1. 常见错误的诊断是模板句（“检查「X」的输入条件与对象”），不是针对本课的现象。
2. 三条提示不是“现象→概念→具体做法”三层。
3. 每步 observableCheck 都是同一句模板。
4. 步骤里有“地面标格子、网格纸”等线下动作，没有转成线上舞台操作。

## 和已可玩启蒙课的关系
SYS-101 映射里 L01/L03/L05 与启蒙课 2/1/5 只是**部分对应**（启蒙课是一次移动 100 步、出场说话、动作顺序），没有网格、方向、障碍、钥匙门，不能拿启蒙课的运行证据替代本单元。

2. 按 TQ-001 重写六节教案：本课专属诊断、三层提示、两项目标不同的练习、两种正确方案。
3. 做成可玩课堂 + 可保存重开的单元作品 + E2E，然后重新复核。
