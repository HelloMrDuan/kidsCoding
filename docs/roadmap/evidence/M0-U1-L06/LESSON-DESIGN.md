# M0-U1-L06《制作几何艺术馆》教学设计（第一阶段，M0-U1 单元收官）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-m0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《制作几何艺术馆》、知识点“对称”、
  预期“能使用对称解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 展品数量（至少 3 件）、展品清单等均为实现选择，不得说成详细稿规定值。
  详细稿缺失需主架构补齐后复核。

## 目标
- 把前面几课的作品整理成一个几何艺术馆：有标题，至少 3 件对称或规则作品。
- 练习 A：方形、镜像小花、五边形；练习 B：六边形、分形树、镜像小花。
- 找错：只有 2 件作品；展出不对称作品。
- 拓展：再加第 4 件作品（分形树）。
- 分层提示：1）艺术馆需要标题吗？2）够 3 件了吗？3）每件都对称吗？

- 不是独立教研，不是儿童试学，不得标 completed。
