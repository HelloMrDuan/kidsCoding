## 本课结构（5 关，全部由事件引擎真实运行判定）

| 关 | 类型 | 内容 | 关键判定 |
|---|---|---|---|
| 1 | 错误实验 | 没切换角色，小狐狸的“开始时 → 走上舞台 → 说早上好”拼到了小鸟名下：先点选预测，再按原样运行 | 必须真实跑出 `too_early`（小鸟抢先上台），显示“预想 vs 实际” |
| 2 | 引导 | 只排第一个节目：按开始旗小狐狸上台；点小狐狸、点小鸟都不再变化 | 拼在小鸟名下 `wrong_actor`；用“被点击时” `nothing_happened`；顺序反 `wrong_order` |
| 3 | 练习 A | 两次登台：开始旗小狐狸先上台，点后台的小鸟再上台 | 小鸟也用“开始时” `too_early`；小鸟没拼 / 小狐狸用点击 `nothing_happened` |
| 4 | 练习 B（调试） | 两段积木都没触发：小狐狸缺事件，小鸟等一个没人摇的铃铛 | 起始程序必失败：先 `no_hat`，修好小狐狸后 `nothing_happened` |
| 5 | 创意 | 小狐狸第一个上台，第二个节目自选（小鸟/小兔子/小青蛙），做“我的小剧场节目单” | 拼错名下 `nothing_happened`；第二位也用开始旗 `too_early`；多一位朋友上台 `wrong_trigger`；3 个选择互不代替 |

完成后：复盘卡（目标回顾、本节真实遇到并修好的错误、What-if：小鸟也用“开始时”会怎样）+ 点选反思 + 作品“我的小剧场节目单”（保存、刷新恢复、真实回放：小狐狸先上台，再点所选朋友）。

原创场景：`apps/web/public/kc-scenes/two-doors.svg`（森林小剧场：红色幕帘、两扇后台门、木头舞台），课堂内联 `TwoDoors` 与之一致；后台朋友半透明，上台后变清楚（`data-onstage`）。已登记 `assets-register.md` 与 `asset-licenses-v1.json`。
