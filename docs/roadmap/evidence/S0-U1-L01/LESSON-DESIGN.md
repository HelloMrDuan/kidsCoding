# S0-U1-L01《认识计算机部件》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-s0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《认识计算机部件》、知识点“设备”、
  预期“能使用设备解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 部件清单与功能配对（显示器-显示、键盘-输入、鼠标-指向、主机-运算、
  音箱-发声）均为实现选择，不得说成详细稿规定值。详细稿缺失需主架构补齐后复核。

## 目标
- 认识 5 个主要计算机部件，并把每个部件配对到正确功能。
- 练习 A：按给定顺序配对 5 个部件；练习 B：打乱顺序仍配对正确。
- 找错：部件配错功能、缺少部件。
- 拓展：再加一个部件（打印机-打印），不破坏原有配对。
- 分层提示：1）这个部件叫什么？2）它用来做什么？3）配对后还缺哪一个？

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 不是基于详细稿的课程，详细稿缺失须另行补齐。
