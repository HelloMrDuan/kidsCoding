# M0-U1-L01《用积木绘制方形》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件：curriculum 目录下无 track-m0 文件，
  代码搜索 M0-U1-L01 与 track-m0 均为 0 结果，台账 detailAssetPresent=false。
- 本设计仅依据台账条目：标题《用积木绘制方形》、知识点“角度”、
  预期“能使用角度解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收（真实执行器、两种不同目标的亲手练习、一条实际错误或
  边界测试、分层纠错、可修改的原创作品、关闭重开验证）。
- 以下所有数值（边长 100/60、转角 90 度、起点等）均为实现选择，
  不得说成详细稿规定值。详细稿缺失是本课的真实缺口，需主架构补详细稿
  后再复核本设计是否与详细稿一致。

## 目标
- 重复 4 次：前进、转 90 度，画出闭合方形。
- 练习 A：边长 100 的方形；练习 B：边长 60、不同起点的方形。
- 找错：转 80 度画不出闭合方形。
- 拓展：换颜色再画一个方形。
- 分层提示：1）方形有几条边？2）每个角转多少度？3）终点回到起点吗？

- 不是独立教研，不是儿童试学，不得标 completed。
