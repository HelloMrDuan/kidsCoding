## 教学目标

学生能用多次采样去掉按键抖动：只有连续 3 次采到按下才算按了一次，中间来回跳的抖动不重复计数，并说清为什么不能把每次跳变都当成一次按键。

## 情景与知识

- 情景：按键接在引脚 2，供 5V 电，采到 0、0、0、1、1、1、0、0、0，算出按了 1 次。
- 知识：合格去抖 = 供电必须是开始后第一个积木且电压恰好 5V + 按键引脚只能是 2、3 + 至少 6 个采样且每个状态只能是 0 或 1 + 恰好一个计数积木且在最后一个采样之后 + 计数必须等于采样算出的次数。
- 去抖规则（实现选择，必须讲明）：按下只有连续 3 次采到 1 才算一次；算过一次后，只有连续 3 次采到 0 才算松开、可以再算下一次；中间 1、0 来回跳都不额外计数。
- 安全与真实性说明（课堂必须讲明）：本课只是模拟模型，不读真实按键，不得冒充真实测量；真实按键工作必须在断电时由老师或监护人指导接线，只用开发板规定的电压。

## 亲手练习（目标不同）

- 练习 A（主课，干净的一次按键）：采样 0、0、0、1、1、1、0、0、0，计数 1。
- 练习 B（抖动的一次按键）：采样 0、1、0、1、1、1、0、1、0、0、0，中间来回跳，仍只算 1 次。

## 找错

- 采样状态 2、采样只有 5 个：均失败。
- 抖动序列数成 2 次、干净按键数成 0 次：均失败，说明计数不是从采样算出来的。
- 按键引脚 7、电压不对：均失败。
- 缺少按键、缺少供电、缺少计数、缺少开始事件：均失败。

## 分层提示

- 第一层：先看供电和按键接对没有。
- 第二层：再数采样够不够 6 个，状态是不是只有 0 和 1。
- 第三层：一段一段找连续 3 个 1，够 3 个才算一次，中间跳变不算。
