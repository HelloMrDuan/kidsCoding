# D0-U3-L06《工程挑战成果展》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-d0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《工程挑战成果展》、知识点“测试”、
  预期“能使用测试解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 项目与结果均为实现选择，不得说成详细稿规定值。
  详细稿缺失需主架构补齐后复核。

## 目标
- 举办工程挑战成果展：有标题，至少 3 个项目，每个项目有问题、方案、测试结果，
  至少一个项目通过测试，至少展示一次根据测试失败做的改进。
- 练习 A：纸桥、警报、信号 3 个项目，信号改进记录；
  练习 B：导览、分类、能源 3 个项目，分类改进记录。
- 找错：项目缺少测试结果；少于 3 个项目；没有任何改进记录。
- 拓展：再加植物项目。
- 分层提示：1）每个项目解决了什么问题？2）测试结果是什么？3）改了什么？

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 不是基于详细稿的课程，详细稿缺失须另行补齐。
- 前置课 D0-U3-L05 尚在 PR #365 待审核未合并，本课台账登记不写
  对未合并任务的依赖，前置关系仅在本设计与 PR 描述中说明。
