# G1-U1-L04《角色出场退场》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U1-L04，年龄 6-9 岁，引擎 blockly。
故事：角色下台也要有动作，不可以突然消失。

## 目标
- 让狐狸从左进入舞台，打招呼后向右退出。
- 验证：出场与退场发生在对白两侧。
- 注意：详细稿未规定本课打招呼的具体文本，执行器接受任何非空打招呼，
  不得把示例文本“大家好！”说成详细稿规定的文本。

## 找错
- 退场先于问候，观众看不到角色：把入场、问候、退场标在三个时间节点。
- 打招呼时不在舞台上、直接隐藏下台、缺少入场/打招呼/退场均为失败。

## 拓展
- 让兔子从另一侧接替入场，执行器仍通过。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 前置课 G1-U1-L03 尚在 PR #275 待审核未合并，本课台账登记不写
  对未合并任务的依赖，前置关系仅在本设计与 PR 描述中说明。
