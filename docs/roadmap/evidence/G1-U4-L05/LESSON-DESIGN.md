# G1-U4-L05《邀请朋友试玩》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U4-L05，年龄 6-9 岁，引擎 blockly。
故事：导演邀请朋友试演新故事，收集真实建议。

## 目标
- 编写试玩任务单，让同伴检查触发入口、对白和结尾。
- 验证：记录至少3条反馈和一次可追踪的修复。

## 找错
- 只问喜欢不喜欢，却没有复现问题：为反馈写操作步骤、预期、实际三列。
- 反馈少于3条、缺少可追踪修复、缺少检查项、缺少开始事件均为失败。

## 拓展
- 邀请第二个朋友复测修复结果：执行器中以 retest 标出，仍通过。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 前置课 G1-U4-L04 尚在 PR #301 待审核未合并，本课台账登记不写
