# G2-U3-L01 键盘控制小船 — 第 1 阶段（结构阶段，非可玩课程）

课程 ID：G2-U3-L01，名称：键盘控制小船，年龄 7-11，引擎 Scratch 3，知识点：侦测。
前置：G2-U2-L06（PR #247，未合并；本课不依赖其合并，仅按顺序开发）。

## 教学目标（与台账详细大纲一致）
1. 理解并能解释侦测：键盘按键是一种事件，角色听到按键才动。
2. 按右方向键，小船 x +10；按左方向键，小船 x -10。
3. 用实际运行结果验证：右键后位置 +10，左键后回到原位。

## 原创项目（真实 Scratch 3 工程结构，已由生成器 + 结构测试证明）
- 舞台：海洋巡逻（原创 SVG：天空、太阳、海浪）。
- 精灵：巡逻小船（原创 SVG：船体、桅杆、双帆），起点 (0, -20)。
- 绿旗 → 回到起点；右方向键 → x +10；左方向键 → x -10（起始工程有找错点：左键也写成 +10，小船回不来）。

## 五关设计（第 2 阶段进实验室后实现为可判分的关卡）
1. 预测：按右键会怎样？按左键呢？先说再运行。
2. 练习 A：按右键 3 次，小船 x 从 0 到 30。
3. 练习 B：先右键再左键，小船回到 0。
4. 找错：左键为什么也往右走？对一对两个按键脚本里的数字。
5. 创意：在 1～20 步范围内改步数（右键步数、左键步数），做一条自己的巡逻路线，导出 .sb3。

## 三层提示与复习
- 看现象：按左键小船还是往右，说明左键脚本的数字不对。
- 想原因：两个按键脚本都写了 +10，左键没有写 -10。
- 去修复：把左键脚本的改变量改成 -10，再右键、左键各按一次验证回到原位。
- 复习：键盘事件、x 坐标加减、回到原位 = 右移与左移抵消。
