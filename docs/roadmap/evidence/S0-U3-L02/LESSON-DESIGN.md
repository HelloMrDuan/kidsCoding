# S0-U3-L02《标注图片素材来源》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-s0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《标注图片素材来源》、知识点“版权”、
  预期“能使用版权解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 图片、作者、来源与许可状态均为虚构实现选择，不得说成详细稿规定值；
  本课不使用、不复制任何真实图片。
- 详细稿缺失需主架构补齐后复核。

## 目标
- 标注图片素材来源：一张图片只有标注完整且获许可才能用——作者非空、
  来源非空、许可状态为 allowed；作品至少使用 3 张这样的图片，图片编号
  不重复。
- 练习 A：小林/学校图库，小梅/家庭相册，小刚/自己创作，均获许可。
- 练习 B：小兔/学校图库，小狐/自己创作，小鸟/公共图库，均获许可。
- 找错：缺少作者；缺少来源；许可未知；许可为不允许；图片编号重复；
  只有 2 张图片。
- 拓展：再加第 4 张图片。
- 分层提示：1）作者是谁？2）从哪里来？3）可以用吗？

## 明确不是什么

- 不是独立教研，不是儿童试学，不得标 completed。
- 不是基于详细稿的课程，详细稿缺失须另行补齐。
- 前置课 S0-U3-L01 已在 main 台账中列出，本课台账登记不新增依赖；
