# G3-U1-L01 用自制积木画图 — 教学设计（未执行验证版）

课程 ID：G3-U1-L01
年龄：9-13 岁
前置：无
焦点：自制积木带参数 size

## 情境与预测

机器人要用同样的五角星花纹装饰六面旗。
预测问题：六面旗的星星如果大小都一样，是不是机器人想要的？如果每面旗的星星
越来越大，画星形的积木里哪一个数在变？

## 知识点

- 自制积木（过程）可以带参数：`画星形 size`
- 过程内：重复 5 次，移动 size 步，右转 144 度，画出一颗五角星
- 主程序：清笔、移到 (-200, 0)、落笔、size=20、重复 6 次调用画星形、size+20、抬笔、x+60、落笔

## 练习 A（目标：参数真的在变）

改 size 的起始值与每次增量，例如起始 10、每次 +30，
运行后检查：6 颗星尺寸递增，且最后一颗星的 size 变量值与预期一致。
验收：VM 中 sprite 最终 x、size 变量、threads=0（参考 VM-RUN.md 的断言方法）。

## 练习 B（目标：迁移与创意，已生成并用 Node VM 运行，非视觉验证）

再加一个颜色参数：过程改为 `画星形 size 颜色`，过程内先 set pen hue 为 color 参数，
再重复 5 次移动 size、右转 144 度；主脚本 color 从 0 起、每次 +30。
文件：examples/scratch/g3/g3-u1-l01-practice-b.sb3，生成器见 build_g3_u1_l01_variants.py。
Node VM 结果：x=160、size=140、color=180、threads=0，VM_RUN_OK。
注意口径：颜色差异未在 Node VM 中目视验证，需真实浏览器截图确认，见 VM-RUN.md；
尺寸逻辑不变（size 仍 20 起、每次 +20、最终 140）已由 VM 变量验证。

## 真实找错

错误：把具体大小写死在过程里，例如移动固定 20 步，而不是移动 size 步。
现象：6 颗星大小完全一样，与“尺寸按输入参数变化”不符。

三层提示：
1. 现象：六面旗的星星都一样大，主程序里 size 明明在变。
2. 原因：过程里的移动步数没有用 size 这个参数，用的是固定数。
3. 修复：把过程里的移动步数改成 size 参数，再完整运行一遍。

## 等效方案（设计，未验证）

- size 序列不同但递增即可，例如 10、30、50、70、90、110 或 20、40、60、80、100、120
- 颜色参数可以是固定色板，也可以是每次 +20 的色调变化
- 旗帜 x 间距可以不同，只要 6 面旗不重叠
