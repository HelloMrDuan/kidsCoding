# G1-U2-L06《小兔子运动会》教学设计（第一阶段，G1-U2 单元收官）

来源：track-g1-detailed-lessons-v1.json 中 G1-U2-L06，年龄 6-9 岁，引擎 blockly。
故事：森林运动会设了赛跑和跳跃两项比赛。

## 目标
- 设计起跑事件、计时、到达终点和结果播报。
- 验证：竞赛开始后计时变化，到达终点才显示结果。

## 找错
- 未出发便显示胜利结果：确认终点判断依赖角色实时位置。
- 计时不变、未到达终点就播报、缺少起跑事件均为失败。

## 拓展
- 增加双人竞赛成绩榜：结果播报后的 scoreboard 仍通过。

## 说明
- 终点线 x=200 是实现选择，详细稿未规定终点坐标，不得说成详细稿规定值。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
