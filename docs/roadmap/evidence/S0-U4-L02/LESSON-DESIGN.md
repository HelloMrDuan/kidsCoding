## 教学目标

学生能用威胁建模解释软件更新：旧版本可能带有已知弱点，官方更新修补它，从而关闭这条威胁；来源不明的更新本身就是新威胁，不能装。

## 情景与知识

- 情景：画图应用和音乐应用都有新版本，要先判断来源、再看修补了什么、装完再检查能不能正常打开。
- 知识：一次合格更新 = 应用 + 目标版本比当前版本更新 + 来源为官方 + 修补说明非空 + 更新后检查（版本一致且能正常打开）。版本号按数字段比较，1.1 比 1.0 新，1.0 不算更新。
- 安全说明（课堂必须讲明）：本课只是课堂模拟，不下载、不安装、不改动真实软件；真实更新必须请老师或监护人检查，只能用官方来源，来源不明的更新一律不装。

## 亲手练习（目标不同）

- 练习 A（主课）：画图应用 1.0 → 1.1，官方来源，修补画笔闪退漏洞，检查 1.1 能正常打开。
- 练习 B（换应用）：音乐应用 2.0 → 2.1，官方来源，修补播放卡顿漏洞，检查 2.1 能正常打开。

## 找错

- 来源不明：本身就是新威胁，失败。
- 目标版本不比当前版本新：不算更新，失败。
- 更新不说明修补了什么：不知道关了哪条威胁，失败。
- 检查版本与最后更新不一致，或更新后打不开：失败。
- 缺少应用、更新、检查、开始事件：均失败。

## 分层提示

- 第一层：先看应用现在是哪个版本。
- 第二层：再看更新来源是不是官方，目标版本是不是更新。
- 第三层：装完检查版本和能不能打开，两个都对才算完成。

## 创意拓展

- 连续两次更新：画图应用 1.0 → 1.1 → 1.2，每次都官方、都有修补说明，最后检查 1.2 能正常打开，仍通过。
