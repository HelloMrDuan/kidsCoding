# G2-U3-L06《水果接力挑战》证据包

Task-ID: G2-U3-L06 ｜ 轨道 G2 / Scratch VM + scratch-render / Kitten LessonWorkspace
状态上限：课程保持 `in_review / outline_not_playable`，教学参数全部为 `proposed`。本证据包只证明工程实现与真实运行行为，不代表独立教研批准、儿童试学或正式发布。

## 实现要点（与契约对齐）

- focusConcept =「随机」（台账与详细目录一致）。学生用 8 种积木搭水果脚本：绿旗、一直重复、重复执行、随机出生（真实 `operator_random`，范围 -200..200）、下落一步、如果碰到篮子、将得分增加、隐藏。
- 篮子（跟随指针）与舞台倒计时（20 秒、接满 5 颗获胜）是课程预置脚本，沙箱逐项核对，学生改不了、删不掉。
- 运行环境：`public/scratch-g2-u3-l06-sandbox.html` 内真实 scratch-vm@5.0.300 + 真实 scratch-render@2.2.84；碰撞由渲染器 `sensing_touchingobject` 判定；造型就绪（包围盒 = 真实尺寸 80×40 / 40×40）后才开跑。
- 判定三层（judge.ts，只看 VM 真实轨迹）：舞台层（结束方式与变量一致）、任务层（逐颗核算：记分须有同帧 true 检查、每颗最多一次、倒计时结束后不得记分）、知识层（每次出生 x 与同帧随机求值相等、出生 ≥3 且不同位置 ≥3）。
- 确定性：沙箱每次运行把 Math.random 换成带固定种子（20261114）的 PRNG，同一程序轨迹逐字可复现；种子在代码与本证据中公开披露，不冒充真随机设备。
- 虚拟时钟：每帧前进 1000/30ms（与 L05 同法），20 秒 ≈ 620 帧；课堂以 33ms/帧的真实节奏播放。
- 预览：未运行时舞台显示真实工程的初始场景（渲染器绘制，水果停在出生高度——其造型上缘按 Scratch 几何超出舞台顶边，落下即全见）。
- 草稿键 `kidscoding-draft:G2-U3-L06`，64KB 上限，保存/恢复 fail-closed；损坏草稿被拒并干净重开。
