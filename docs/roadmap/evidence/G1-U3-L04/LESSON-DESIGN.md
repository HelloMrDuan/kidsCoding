# G1-U3-L04《碰到障碍停下来》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U3-L04，年龄 6-9 岁，引擎 blockly。
故事：乌龟在森林小径行走，碰到石头就必须停下。

## 目标
- 通过触碰检测，碰到障碍时速度设为0并播放警告。
- 验证：未碰撞可移动，碰撞后保持静止。

## 找错
- 撞到石头之后仍继续移动：检查碰撞判断和停止动作是否放在同一控制路径。
- 缺少触碰处理、缺少开始事件均为失败。

## 拓展
- 设计绕开障碍的二级方案：执行器中以 detour 标出停下后的绕障，仍通过。

## 说明
- 障碍位置 x=100 是实现选择，详细稿未规定障碍坐标，不得说成详细稿规定值。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
