# G1-U3-L06《互动故事分支》教学设计（第一阶段，G1-U3 单元收官）

来源：track-g1-detailed-lessons-v1.json 中 G1-U3-L06，年龄 6-9 岁，引擎 blockly。
故事：故事书的读者可以选“去河边”或“去山坡”两条路。

## 目标
- 设置choice选择与两段分支剧情，走完后显示不同结局。
- 验证：choice=river看到河边，choice=hill看到山坡。

## 找错
- 两个按钮都显示相同场景：逐条运行两种选择，对照不同的结果。
- 缺少分支、缺少开始事件均为失败。

## 拓展
- 增加隐藏的第三结局：choice=forest 看到森林。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
