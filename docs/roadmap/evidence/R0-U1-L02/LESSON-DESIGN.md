## 教学目标

学生能按“供电 → 接 LED → 记点亮前光敏读数 → 开灯 → 记点亮后读数”的顺序完成一次模拟点灯，并用点亮后读数上升说明传感器检测到了灯光。

## 情景与知识

- 情景：给开发板供 5V 电，接一颗红 LED，开灯后光敏传感器的读数从 200 升到 800，说明灯真的亮了。
- 知识：合格点灯 = 供电必须是开始后第一个积木且电压恰好 5V（低于 5V 点不亮，高于 5V 不安全，均失败）+ LED 引脚只能是 11、12、13 且不重复 + 每颗 LED 按接灯、点亮前读数、开灯、点亮后读数的顺序走完 + 读数在 0–1023 内 + 点亮后读数大于点亮前读数。
- 传感器联系：本课台账知识点是传感器，执行器用光敏读数上升作为灯亮的模拟证据；读数不上升，说明传感器没有检测到点亮，实验不算完成。
- 安全与真实性说明（课堂必须讲明）：本课只是模拟模型，不接真实电路、不通真实电、不读真实传感器，不得冒充真实硬件运行；真实接线必须在断电时由老师或监护人指导，只用开发板规定的电压。

## 亲手练习（目标不同）

- 练习 A（主课）：供电 5V，红 LED 引脚 13，光敏读数 200 → 开灯后 800。
- 练习 B（换灯）：供电 5V，绿 LED 引脚 12，光敏读数 150 → 开灯后 700。

## 找错

- 电压 3V：不足，失败；电压 9V：不安全，失败。
- 引脚 5：不在 11、12、13 中，失败。
- 点亮后读数不上升、读数超出 0–1023、实验没走完：均失败。
- 缺少供电、缺少开始事件：均失败。

## 分层提示

- 第一层：先看电压是不是 5V。
- 第二层：再看引脚对不对，顺序有没有跳步。
- 第三层：比较点亮前后的读数，上升了才算灯亮。

## 创意拓展

- 点亮两颗 LED：红 LED 引脚 13（200 → 800）后再点绿 LED 引脚 12（150 → 700），两颗都走完，仍通过。
