# S0-U2-L06《家庭网络安全海报》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-s0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《家庭网络安全海报》、知识点“安全”、
  预期“能使用安全解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 海报标题、主题与规则内容均为实现选择，不得说成详细稿规定值。
  详细稿缺失需主架构补齐后复核。

## 目标
- 制作家庭网络安全海报：先有开始事件与海报标题，至少包含 3 条规则，
  每条规则主题来自本单元所学（口令、双因素验证、隐私、钓鱼消息、
  应用权限），主题不重复，规则内容非空；最后写明求助方式。
- 练习 A：家庭网络安全海报；口令/不分享口令，钓鱼消息/可疑消息请大人看，
  应用权限/不乱给权限；求助：遇到问题请告诉老师或监护人。
- 练习 B：我们家的安全海报；双因素验证/验证码不告诉别人，隐私/
  隐私信息不分享，口令/口令要够长够杂；求助同上。
- 找错：只有 2 条规则；主题重复；缺少标题；缺少求助方式；规则内容为空。
- 拓展：再加第 4 条规则。
- 分层提示：1）少了哪一类安全知识？2）这条规则家里能做到吗？
  3）遇到问题找谁？
