# M0-U1-L02《认识旋转角度》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-m0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《认识旋转角度》、知识点“角度”、
  预期“能使用角度解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 朝向 0 度为初始方向、右转为加、左转为减、目标 90 度等均为实现选择，
  不得说成详细稿规定值。详细稿缺失需主架构补齐后复核。

## 目标
- 理解右转与左转对朝向的影响，能转到指定角度。
- 练习 A：右转 90 度到达目标 90 度；练习 B：左转 270 度同样到达 90 度。
- 找错：右转 80 度未达到目标 90 度。
- 拓展：右转 360 度回到初始朝向。
- 分层提示：1）右转是加还是减？2）还差多少度？3）反方向转多少度也能到？
