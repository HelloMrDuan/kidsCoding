# EDU-102：第 11 课真实独立对白验收

2026-10-11；课程 `lesson-11-duo-rehearsal`。开发基线 `c6d893f90c00a8d5939bd7aeb23c9bf7f18d7bd9`，基线 main 8/8 CI 成功。仅领取 EDU-102，EDU-103 未实施。

## 可玩的能力与教学闭环

- 复用 EDU-101 的真实 Blockly 顺序解释器。狐狸、小熊各有位置、对白及动作状态；`say_line` 将对白写给当前角色，小熊说“我们一起出发吧！”，狐狸问候为“你好！”。本课是受限教学解释器，不声称完整 Scratch 多脚本 VM。
- 每次运行从 0/0、两个空对白开始。重置和编辑取消待执行的指令；重复运行不积累位置或日志。只给小熊说话时，狐狸的对白和位置不受影响。
- 观察起点和任务 → 预测切换后谁开口（猜错也能继续）→ 两位朋友独立移动 100 步、对白为空 → 小熊独立说话 → 亲手把对白交错朋友并修复 → 改造作品、解释归属 → 本机保存、重开修改和重新验证。
- 调试任务必须实际运行“开始、移动、说话、切换、移动”，观察狐狸开口、小熊无目标对白。仅运行正确程序不能跳过这项学习活动。
- 分层提示依次指出气泡现象、解释独立对白、提示调整说话目标；不直接用成功动画替代孩子的程序。
- 标准作品为“开始、狐狸移动、切换、小熊移动、说话”。创意作品可在切换前另给狐狸加问候；问候可放在狐狸移动前或后。目标对白始终由小熊说，验收实际位置和消息而非唯一积木答案。
- 完成页能运行、修改、验证后保存；编辑撤销通过状态。浏览器存储失败显示“尚未保存”，不伪造云同步、发布、认证分数。

| 类型 | 可复现证据 |
