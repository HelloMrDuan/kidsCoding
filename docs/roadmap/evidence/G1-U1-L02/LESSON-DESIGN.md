# G1-U1-L02《与兔子轮流说话》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U1-L02，年龄 6-9 岁，引擎 blockly。
故事：兔子和狐狸第一次见面，要轮流介绍自己的名字。

## 目标
- 安排狐狸说“你好”，兔子再回应“很高兴见到你”。
- 验证：两句对白按狐狸→兔子的顺序出现。

## 找错
- 两位角色同时说话造成重叠：拆开两个角色的说话时机，逐句运行对照。
- 顺序颠倒、缺少第二句、缺少开始事件均为失败，执行器均有对应测试。

## 拓展
- 加入第三句角色告别台词，执行器仍通过。
