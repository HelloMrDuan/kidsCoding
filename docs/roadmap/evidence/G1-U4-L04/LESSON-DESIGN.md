# G1-U4-L04《修复对白顺序》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U4-L04，年龄 6-9 岁，引擎 blockly。
故事：第一次彩排总有两个人同时喊台词。

## 目标
- 对照时间轴逐句调整事件与等待时间。
- 验证：狐狸说完之后兔子再说，不出现重叠。

## 找错
- 减少等待导致两句重叠：让动画暂停在两段对白交接点。
- 顺序颠倒、同时说话、负等待导致重叠、缺少开始事件均为失败。

## 拓展
- 让观众点击才触发下一段：执行器中以 wait_for_click 标出，仍通过。

## 说明
- 每句时长 2 秒是实现选择，详细稿未规定对白时长，不得说成详细稿规定值。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 前置课 G1-U4-L03 尚在 PR #299 待审核未合并，本课台账登记不写
  对未合并任务的依赖，前置关系仅在本设计与 PR 描述中说明。
