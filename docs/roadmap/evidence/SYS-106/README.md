# SYS-106 G0 网格寻路引擎

- 引擎：`apps/web/src/features/lessons/grid/grid-engine.ts`（纯函数，按真实程序逐块运行，输出每块一帧）
- 积木：向上/下/左/右走一格、向前走一格、向左转、向右转、捡起钥匙、打开树洞门（`register-kids-blocks.ts`）
- 舞台：`grid-stage.tsx`，卡通森林网格（草地格、石头、小河、金钥匙、树洞门、蘑菇屋目标），小狐狸是 V2 插画角色，带朝向箭头和撞击星星
- 能力登记：`features/curriculum/engine-capabilities.ts`，G0-U1 所需 `direction`、`path_obstacles` 已实现；未实现能力不冒认
- **不解锁课程**：G0-U1 仍是 L1、`playable: false`，要等教案重写和重新复核

## 正反例（grid-engine.test.ts）
| 关卡 | 通过 | 失败 |
| --- | --- | --- |
| 直走三格 | 向前×3；向右走一格×3 | 少走一格（提示“往右还差 1 格”）、走出地图 |
| 绕开小河 | 两条不同路线 | 穿过小河（落水） |
| 转弯避石头 | 转弯绕行；先上再右 | 直走撞石头（标出撞击格） |
| 钥匙开门 | 捡钥匙→开门→前进 | 直接撞门、没钥匙开门、空格捡钥匙、离门太远开门 |
