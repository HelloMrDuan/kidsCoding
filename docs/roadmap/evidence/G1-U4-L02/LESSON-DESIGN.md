# G1-U4-L02《绘制场景草图》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U4-L02，年龄 6-9 岁，引擎 blockly。
故事：场景美术师需要把脑中的故事变成能操作的画面。

## 目标
- 绘制三张分镜草图并标注角色位置与道具。
- 验证：每张草图标明角色、背景和触发事件。

## 找错
- 图画漂亮却没有动作或触发标记：用不同颜色框出角色与交互对象。
- 缺少触发、缺少角色、少于三张、缺少开始事件均为失败。

## 拓展
- 把草图做成简单动画原型：执行器中以 animate 标出，仍通过。
