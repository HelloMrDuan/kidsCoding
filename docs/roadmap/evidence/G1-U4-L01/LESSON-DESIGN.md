# G1-U4-L01《规划三幕故事》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U4-L01，年龄 6-9 岁，引擎 blockly。
故事：校园戏剧节要求团队先规划三幕故事再开始编码。

## 目标
- 制作开端、冲突、解决三幕剧情时间线。
- 验证：每幕有一条可辨识的事件与人物目标。

## 找错
- 只有开场没有问题或解决段落：写下三幕各自发生的变化。
- 缺少目标、顺序错误、缺少开始事件均为失败。

## 拓展
- 为每幕加入一句旁白：执行器中以 narration 标出，仍通过。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 前置课 G1-U3-L06 尚在 PR #293 待审核未合并，本课台账登记不写
  对未合并任务的依赖，前置关系仅在本设计与 PR 描述中说明。
