# R0-U1-L01《认识开发板与供电》教学设计（第一阶段）

## 来源与诚实声明
- 本课在 main 上没有详细稿文件，核查方法与结论见 M0-U1-L01 的
  LESSON-DESIGN.md：curriculum 目录无 track-r0 文件，台账
  detailAssetPresent=false。
- 本设计仅依据台账条目：标题《认识开发板与供电》、知识点“传感器”、
  预期“能使用传感器解释并完成关键操作，并展示可运行的结果或设计证据”，
  以及通用验收。
- 开发板部件、5V 供电、传感器 0-1023 范围、读数 512/800 等均为实现选择，
  不得说成详细稿规定值。详细稿缺失需主架构补齐后复核。

## 目标
- 认识开发板、USB 线、电源、传感器，接通 5V 电源，指示灯亮，读到传感器数值。
- 练习 A：接通电源，读数 512；练习 B：接通电源，读数 800，仍在范围内。
- 找错：未接通电源、传感器读数超出 0-1023 范围、缺少部件。
- 拓展：再读第二个传感器数值，两者均在范围内。
- 分层提示：1）开发板上哪个是电源口？2）灯亮了吗？3）读数在范围内吗？

- 不是真实硬件运行：本执行器是开发板模拟模型，不是物理开发板实测。
- 不是独立教研，不是儿童试学，不得标 completed。
