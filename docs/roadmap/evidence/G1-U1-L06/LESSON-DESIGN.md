# G1-U1-L06《完整森林童话》教学设计（第一阶段，G1-U1 单元收官）

来源：track-g1-detailed-lessons-v1.json 中 G1-U1-L06，年龄 6-9 岁，引擎 blockly。
故事：森林剧院迎来第一场正式的童话首演。

## 目标
- 完成开场、相遇、冲突、结尾四部分的狐狸兔子故事。
- 验证：作品可完整播放且至少两位角色有不同对白。

## 找错
- 故事跳过结尾或对白顺序混乱：使用四格分镜对照播放时间线。
- 只有一位角色说话、章节缺少对白、对白在章节外均为失败。

## 拓展
- 设计两个不同的结局，执行器仍通过。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 前置课 G1-U1-L05 尚在 PR #278 待审核未合并，本课台账登记不写
  对未合并任务的依赖，前置关系仅在本设计与 PR 描述中说明。
