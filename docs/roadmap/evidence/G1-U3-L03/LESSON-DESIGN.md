# G1-U3-L03《记录得到的星星》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U3-L03，年龄 6-9 岁，引擎 blockly。
故事：小狐狸获得一颗星星，记分板应及时变化。

## 目标
- score初始0，每拿到新星星加1，展示在屏幕。
- 验证：拾取3颗不同星星得到score=3。

## 找错
- 重复碰同一星星导致重复加分：为被拾取对象设置已收集状态。
- 执行器中已收集星星再次拾取不加分；直接设定分数失败。

## 拓展
- 设置达5分才解锁彩蛋：拾取5颗不同星星时 easter_egg 为真。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 前置课 G1-U3-L02 尚在 PR #289 待审核未合并，本课台账登记不写
  对未合并任务的依赖，前置关系仅在本设计与 PR 描述中说明。
