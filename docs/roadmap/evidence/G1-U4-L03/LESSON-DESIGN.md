# G1-U4-L03《给人物分配任务》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U4-L03，年龄 6-9 岁，引擎 blockly。
故事：两位小演员都想控制同一辆小车。

## 目标
- 将狐狸脚本负责行驶、兔子脚本负责提示与计时。
- 验证：两位角色有独立任务，不重复控制小车。

## 找错
- 同一动作被两个脚本同时执行造成抖动：在任务单上写清角色职责与脚本归属。
- 执行器先检查小车控制者唯一性，再检查各自任务归属。

## 修复记录
- 首版测试中 both_drive 用例失败：执行器先报“兔子脚本负责提示与计时”，
  而非“抖动”。已调整检查顺序，先判小车控制者唯一性，6 个测试全部通过。

## 拓展
- 增加第三位记录员角色：执行器中以 turtle/record 标出，仍通过。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。
- 前置课 G1-U4-L02 尚在 PR #297 待审核未合并，本课台账登记不写
  对未合并任务的依赖，前置关系仅在本设计与 PR 描述中说明。
