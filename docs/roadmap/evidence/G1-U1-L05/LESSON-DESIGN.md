# G1-U1-L05《字幕与旁白》教学设计（第一阶段）

来源：track-g1-detailed-lessons-v1.json 中 G1-U1-L05，年龄 6-9 岁，引擎 blockly。
故事：剧场字幕员抱怨解说的文字总是挡住角色。

## 目标
- 给片头加标题字幕，剧情中改用短旁白。
- 验证：片头字幕结束后才出现角色对白。
- 注意：详细稿只要求“短旁白”，未规定具体字数，执行器定义短为
  不超过 20 字，是实现选择，不得说成详细稿规定值。

## 找错
- 长字幕一直不消失遮挡人物：核对字幕显示时间与对话开始时间。
- 对白在标题隐藏前出现、标题从不隐藏、缺少标题、旁白过长均为失败。

## 拓展
- 提供一句无障碍说明字幕，执行器仍通过。

## 明确不是什么
- 不是网页课堂可玩课程，未接入任何 lab 页面，未改 web 代码。
- 不是独立教研，不是儿童试学，不得标 completed。

  对未合并任务的依赖，前置关系仅在本设计与 PR 描述中说明。
