# 05｜国内头部少儿编程页面参考图谱、取舍表与视觉复刻要求

> **2026-10-11 修订。开发者开始设计前必须阅读。** 目标是使 KidsCoding 在信息层次、视觉精度、学习动线、触控响应、动效和真实可玩程度上与国内优秀少儿编程产品处于相近水平。不是简单“有点像”；但不得盗用商标、原创角色、插画、付费课件、源代码或逐像素复制可识别的专有页面。
>
> **证据边界**：公开官网能证明对方主张的教学法；公开展示图可以说明部分历史/宣传界面布局，不能证明该产品当前登录后学生端的所有界面。没有账号/授权不宣称已登录看过其付费课程。每张参考图都必须打上 [官方现有展示] / [第三方历史截图] / [需要真实学员端核验] 标签。

### “高度靠近”明确怎么做

- **学习地图**：采用可滚动连续冒险世界、强透视/轻 2.5D 地形、曲线关卡路径、角色当前位置、大型重点课节点；KidsCoding 自己的森林/草地/花园/毕业岛原创构图，而不是普通表格网格替代。
- **图形化课堂**：桌面学习环境必须同时看得到关卡目标、实时舞台、Blockly 真编辑器；右侧或底部有清晰运行/重置/保存/下一步，角色和代码能同步响应。参考工具型工作台的“密度和层次”，不能完全照用别人的布局像素。
- **课内练习**：参考成熟平台“短讲—动手—即时反馈—再次尝试—创造性挑战”的连续节奏，不能播放一段漂亮动画就发星星。
- **作品与成长**：参考项目型教学，以孩子自己的真实作品截图/可重播结果为内容；缺作品时留真实空状态，不用虚构样例假装学员成果。
- **专业分级**：G0/G1 优先卡通空间感，G2/G3/高龄 Python 保留品牌感但编辑区专业；家长/后台弱化童趣、强调数据可追溯。

## B. 视觉还原目标矩阵（把形容词转换成验收项）

| 维度 | 可参考的成熟做法 | KidsCoding 切实落地 |
| --- | --- | --- |
| 首屏焦点 | 单一推荐关卡、场景引导而不是数十入口争抢 | 首屏 1 个主要“继续第 N 关”操作；最近作品/进度为次级 |
| 画面素材 | 每个单元有高品质、连贯的世界插图 | 至少森林、草地、花园、毕业岛 4 组原创地形；统一透视、笔触、阴影、比例 |
| 关卡地图 | 视觉路径与完成奖励叠加 | 12 节明确坐标、曲线连线，完成/当前/下一关/锁定 4 个不同形态，不仅仅背景颜色 |
| 运行舞台 | 角色精灵、道具、动作、对白一屏明确 | 舞台真实精灵位置/场景切换/对话/事件等待/运行错误，在视图可见 |
| 积木编辑 | 分类鲜明、拖拽目标大、工作区可缩放 | Blockly Toolbox、分类视觉、缩放、运行重置、手机分区模式，支持真实操作 |
| 游戏反馈 | 完成态有动效/奖励，但不干扰下一步 | 成功动作+结果说明+下一步 CTA；失败显示差异与 3 层提示，无假成功 |
| 项目进度 | 章节和课程数量可追踪 | 4 单元进度 + 当前课步骤 + 可重播作品；432 规划数标注为规划而非可玩 |
| 情绪设计 | 可鼓励、不说“你错了” | 出错精准可修、角色鼓励，预测错误不等于失败 |
| 学习延展 | 做完以后继续改项目、重复运行 | 一个课内创意挑战、不同参数或另一解决路径；不依靠标准积木序列作为唯一评价 |
| 家长信任 | 原创作品、知识点、上次学习信息清晰 | 只展示存在数据，客户端练习反馈不能伪装服务端成绩 |

## C. 图像和素材的可落地授权流程

1. 竞品参考图**只能存链接**和内部对比截图记录，不把对方人物、商标、角色、课件素材复制进产品 public 目录。
2. 素材按 `asset_id`、`scene`、`prompt_or_brief`、`source_url`、`creator`、`license`、`approved_by`、`hash_sha256`、`review_date` 建独立台账；缺许可不进入正式发布。
3. 自有原创生成图/授权图库/自绘 SVG 可放在项目源码和设计稿，能重现出处；形似不代表可以直接复用对方的原图。
4. 所有对比截图需要页面标识、来源 URL、截取时间、分辨率、授权状态；如果竞品学员端不可见，写“结构推断/待核”，不要伪造现场截图。
5. 对标采用“逐元素差距分析”：展示层级、模块大小、交互区分、反馈时延、字体与触控。对现有 KidsCoding 截图每条写具体差距，不能只写“质感不足”。

## E. 严格交付规定

不接受以下交付方式：只用 AI 生成一张 UI 图当开发完成；一次性画出全站却没有真正的业务/事件闭环；使用竞品全页截图当页面背景；把竞品专有课件照搬到自有课程；没看真机就称手机端完善。**高度参考的是可迁移的方法、可见布局和真实使用体验，成果必须有独立的原创身份与可交互实现。**
