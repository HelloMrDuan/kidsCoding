# KidsCoding 页面视觉重做 · V2 设计交接规范

**交付日期：** 2026-10-11  
**定位：** 用户已认可的 V2 视觉与交互基线（APPROVED DESIGN；非业务完成），不作为已实现业务。  
**范围：** 10 个页面、3 个手机断点展示、单文件可离线打开的交互式 HTML、截图、样例交互检查。  
**仓库：** `https://github.com/HelloMrDuan/kidsCoding`。本设计在 GitHub 的 `docs/design/kidscoding-v2/` 留存；仅将 UX-001 标为设计阶段进行中，不修改 Next.js 业务代码。

## 1. 用户拒绝 V1 的问题及 V2 纠偏

| V1 问题 | V2 做法 |
| --- | --- |
| 幼儿园化、童话感过重、吉祥物与颜色喧宾夺主 | 改为教育科技 SaaS 设计：海军蓝左导航 + 云白内容区域 + 科技蓝 CTA；角色只用于作品/课程视觉，不再主导每个页面 |
| 星球、圆角、渐变、气泡叠加，像概念作品 | 统一 8–14px 操作容器圆角、规则栅格、明晰标题/导航/按钮层次；减少装饰 |
| 首页“好看但不知道先做什么” | 只突出“继续当前课程”，旁边显示学习进度；课程方向、作品展示居次级 |
| 地图没有清晰对应的课程结构 | 四单元 × 三节课，共 12 个独立启蒙关卡；当前/已学/预览明确区别，模型不重复加入 432 总目录 |
| Blockly 工作台对小孩过度玩具化 | 专业三域：教学任务/真实 Blockly 目标区域/舞台；反馈与下一步独立展示；移动端任务/积木/舞台标签切换 |
| 作品、家长、后台像装饰页 | 作品管理可见“预览/编辑”的位置；家长要真实作品证据；后台区分教案、引擎、审查、发布状态 |

## 2. 真实公开参考及采用决策

- **西瓜创客**：公开下载页 `https://www.xiguacity.cn/download` 有课程继续学习面板、左侧导航与学习状态。公开课程页 `https://www.xiguacity.cn/curriculum` 明确 PBL 项目制路线。借鉴以当前任务为主的首屏信息架构和从作品形成能力的课程流，**不采用其品牌色、专属角色、课程图**。
- **核桃编程**：参考公开课程 `https://official.hetao101.com/curriculum` 与公开第三方历史工作区截屏，借鉴工具栏、编辑器和操作区域的明确区分，不能宣称获取了当前付费学生端。
- **编程猫**：`https://pc.codemao.cn/` 和 `https://lab.codemao.cn/`，借鉴创作平台的工具层次、作品作为成果的设计思路，不复制素材和积木引擎。

设计参照布局与体验，不复刻受保护界面、角色、课件、源码。

## 4. 视觉变量 V2（提案）

- 页面底色：`#f3f6fb`；卡片：`#ffffff`；线条：`#e7edf5`。
- 左侧导航：`#152238` / `#1c2c46`；文字：`#18243a`；次级：`#6f7d92`。
- 品牌动作：`#2463eb`；成功提示：`#148767`；警告：`#ad6b20`；错误：`#d64c4c`。
- 圆角：操作按钮 8px；主要卡片 14px；不重复使用超大圆角和浮夸拟物。
- 1440 桌面：222px 左导航；右侧内容自适应；顶部导航 76px；任务卡/工具区分层。
- 390 手机：顶部 58px，底部 62px 主导航；工作台切换为“任务/积木/舞台”，绝不能强行三栏压缩。
- 字体：现代无衬线中文；标题 22–28px，正文 12–14px 仅为原型参考，正式儿童课堂关键指示需要进行阅读与对比度验证后适当放大。

## 5. 关键交互

1. 左侧菜单/手机底栏：10 个页面真实切换，不重新加载原型。
2. 课程地图：4 个单元 × 3 课（第 1～12 课），可选择单元，已学/当前/未开放仅为模拟状态。
3. Blockly 课堂：提示显隐、运行示意动画、重置、下一步反馈；**演示积木不可拖拽，未调用真正 Blockly**。
4. 手机课堂：任务、积木、舞台独立切换；防止代码区被压缩不可用。
5. Python：点击运行显示**预设示例输出**，不执行 Python 解释器。
6. 目录：不同路线过滤；规划路线没有虚假的“现在开始课程”。
7. 所有作品封面、学情数字、签到信息、运行与保存演示，均为**视觉示意，不是学员真实记录**。

## 6. 交接 Codex 时的约束

**V2 设计方案已获用户审核同意。本 PR 提交设计基线，后续开发必须按单一 Task-ID 分批实施。** 实现必须遵守仓库 `docs/roadmap/11-TASK-EXECUTION-POLICY.md`，一次仅实现一个 Task-ID。优先对照 `UX-001~004`、`UX-101~105`、`UX-201~206`、其他逐页面工作包。不得直接将单文件原型覆盖业务页面。

具体约束：
- 原型设计数据和示例“运行”不可替换真实课程状态和真实引擎；真 Blockly/Scratch VM/Pyodide 都要通过仓库实际浏览器 E2E。
- 不得将示例学员记录或 AI 绘制封面当真实学生作品，公共作品需要独立授权。
- 对所有素材保留原创/生成/许可记录，产品投产前执行版权审阅。
- `task-register.json`、`lesson-task-register.json` 与 `TASK-CHANGELOG.md` 只有完成真实代码 PR/CI/合并/main CI 后，才允许相应更新 `completed`。
- 验收尺寸：1440×900、768×1024、375×812；Chromium 键盘/触摸/慢网、对比度/字号、图片性能、减弱动效都须验证。
